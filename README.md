# Соати гӯё

Говорящие часы для Android 10 и новее. Автор: AMIN JON.

Версия 5.4.2: обновлены экраны часов, расписания и настроек; исправлен вылет главного экрана. Добавлен учёт режима «Не беспокоить»: Настройки → Расписание и объявления. Опция выключена по умолчанию. При её включении автоматическое озвучивание, сигналы и вибрация приостанавливаются на время системного режима.

[Скачать APK](https://github.com/baqha0717-netizen/Talking-clock./releases/latest)

Устанавливайте поверх прежней версии без удаления приложения. Голоса и настройки сохранены. Озвучивание и расписание работают без интернета. Интернет нужен проверке и загрузке обновлений; загрузка и установка выполняются по нажатию пользователя.

Подпись и целостность APK проверяются до публикации. Работа на физическом телефоне с TalkBack/Jieshuo ещё не проверена.

В репозитории размещаются подписанные дистрибутивы, публичные метаданные и автоматизация публикации. Приватные исходники и ключ подписи сюда не включаются.
